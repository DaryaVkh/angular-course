# Первое приложение на CLI

🟢 Уровень: базовый · ⏱ 40–60 минут · Тема: [start](../../lecture/basics.md)

### Как запускать

Это **терминальная задача**: приложение вы создаёте сами, с нуля.
Ничего запускать из этого репозитория не нужно — и создавать проект внутри него **тоже не нужно**.

```bash
# перейдите в любую папку ВНЕ этого репозитория, например
cd ~/angular-playground   # или C:\dev\angular-playground
```

> Почему вне репозитория: здесь один общий `angular.json` на 53 проекта и общий
> `package.json`. Вложенный workspace со своими зависимостями сломает и линтер, и сборку.

---

## Information

Angular CLI — основной инструмент работы с Angular. Пока вы не создали проект руками
и не почувствовали, что именно генерируется, `angular.json` остаётся набором непонятных
букв. Эта задача — про мышечную память: `ng new` → `ng serve` → `ng generate` → `ng build`.

Собираем маленькое приложение «Доска задач» (Task Board): список задач, карточка задачи,
сервис с данными и пайп для относительного времени. Логика намеренно примитивная —
задача не про неё, а про инструмент.

### Шаг 3. Сгенерировать код — только через CLI

Создайте **командами `ng generate`** (руками файлы не создавать):

| Что           | Требование                                                                   |
| ------------- | ---------------------------------------------------------------------------- |
| `Task`        | Интерфейс: `id: number`, `title: string`, `done: boolean`, `createdAt: Date` |
| `TaskService` | Сервис с массивом задач в `signal` и методом переключения `done`             |
| `TaskList`    | Компонент, стратегия обнаружения изменений — **OnPush**                      |
| `TaskItem`    | Компонент, **OnPush**, с инлайновым шаблоном и инлайновыми стилями           |
| `TimeAgo`     | Пайп, превращающий `Date` в строку вида «5 минут назад» ![pharaoh](image.png)|

Требования к генерации:

- `TaskItem` создаётся **одной командой** — без последующего ручного удаления
  файлов шаблона и стилей;
- `OnPush` задаётся флагом, а не дописывается руками после генерации;
- перед каждой командой полезно прогнать её с `--dry-run`.

### Шаг 4. Связать

Минимальная работоспособность:

- `TaskService` отдаёт список задач (3–5 штук, захардкоженных);
- `TaskList` получает список из сервиса через `inject()` и рендерит задачи
  через блок `@for` с `track`;
- `TaskItem` принимает задачу через `input()` и эмитит событие через `output()`
  при клике по чекбоксу;
- `TimeAgo` применяется к `createdAt` в шаблоне `TaskItem`;
- `TaskList` подключён в корневом компоненте и виден в браузере.

Красивая вёрстка не требуется — работающая функциональность требуется.

## Constraints

- **Ни одного файла, созданного вручную.** Всё, что можно сгенерировать через
  `ng generate`, должно быть сгенерировано. Редактировать содержимое созданных файлов —
  можно и нужно.
- **Никаких `NgModule`.** Только standalone-компоненты.
- **Никаких `*ngIf` / `*ngFor`.** Только блоки `@if` / `@for`.
- Не копируйте проект из этого репозитория и не создавайте его внутри репозитория.

<details>
  <summary>Подсказка 2 — что писать в сервисе</summary>

```ts
@Injectable({ providedIn: 'root' })
export class TaskService {
  private readonly state = signal<Task[]>([
    { id: 1, title: 'Прочитать лекцию', done: true, createdAt: new Date(Date.now() - 3_600_000) },
    { id: 2, title: 'Создать проект через ng new', done: false, createdAt: new Date() },
  ]);

  readonly tasks = this.state.asReadonly();

  toggle(id: number): void {
    this.state.update((tasks) => tasks.map((task) => (task.id === id ? { ...task, done: !task.done } : task)));
  }
}
```

</details>

<details>
  <summary>Подсказка 3 — input / output в современном Angular</summary>

```ts
@Component({
  selector: 'app-task-item',
  changeDetection: ChangeDetectionStrategy.OnPush,
  imports: [TimeAgoPipe],
  template: `
    <label>
      <input type="checkbox" [checked]="task().done" (change)="toggled.emit(task().id)" />
      {{ task().title }} — {{ task().createdAt | timeAgo }}
    </label>
  `,
  styles: `
    label {
      display: block;
    }
  `,
})
export class TaskItem {
  readonly task = input.required<Task>();
  readonly toggled = output<number>();
}
```

</details>

<details>
  <summary>Подсказка 4 — почему CLI ругается на имя пайпа</summary>

Имя класса и имя пайпа в шаблоне — разные вещи. `ng g pipe time-ago` создаст класс
`TimeAgo` (в v20 — в файле `time-ago-pipe.ts`) с `name: 'timeAgo'`. В шаблоне
используется именно `timeAgo`, и пайп нужно добавить в `imports` компонента.

</details>
