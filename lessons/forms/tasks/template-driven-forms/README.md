# Template-driven forms

### Как запускать

Из корня репозитория:

```bash
npm run serve:forms-template-driven-forms
```

Откройте `http://localhost:4200`.

## Задание

Переведите форму записи на мастер-класс на template-driven forms. В стартовом приложении поля проверяет браузер, а обработчик `submit` показывает общее подтверждение.

1. Подключите `FormsModule` и получите ссылку на `NgForm` в шаблоне. Зарегистрируйте каждое поле через `ngModel` и `name`. Объедините имя и почту в группу `contact` с помощью `ngModelGroup`.
2. Настройте валидацию средствами Angular. Имя обязательно и должно содержать минимум два символа. Почта обязательна и должна проходить проверку формата. Нужно выбрать мастер-класс и отметить флажок подтверждения.
3. Показывайте сообщение рядом с невалидным полем после того, как пользователь покинул его. Кнопка «Записаться» должна быть отключена, пока форма невалидна.
4. Обработайте отправку через `ngSubmit`. Покажите в подтверждении ниже формы имя и название выбранного мастер-класса. Данные заявки должны включать вложенную группу `contact` с именем и почтой, выбранное занятие и отметку подтверждения.
5. По кнопке «Очистить» сбрасывайте значения и состояние формы через `resetForm()` и убирайте подтверждение.

### Как проверить себя

- При открытии страницы поля пустые, сообщения об ошибках скрыты, а кнопка записи отключена.
- Введите имя из одного символа или почту без `@` и покиньте поле. Рядом появится сообщение об ошибке. Исправьте значение, и сообщение исчезнет.
- Заполните контакты, выберите занятие и отметьте флажок. Кнопка записи станет доступна. После отправки подтверждение покажет введённое имя и выбранное занятие.
- Нажмите «Очистить». Поля вернутся в исходное состояние, ошибки и подтверждение скроются, кнопка записи снова будет отключена.
