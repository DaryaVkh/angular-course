# Reactive Forms

### Как запускать

Из корня репозитория:

```bash
npm run serve:forms-reactive-forms
```

Откройте `http://localhost:4200`.

## Задание

В стартовом приложении можно забронировать одно место на экскурсию. Форма уже использует `ReactiveFormsModule` и вложенную группу `contact`. Псевдосервер `BookingService` возвращает Observable с задержкой: загружает экскурсии, проверяет доступность почты и оформляет бронь. Данные хранятся в памяти и возвращаются к исходным после перезагрузки страницы.

Расширьте форму до бронирования для группы.

1. Создайте реактивную FormGroup для уже реализованных полей на app.component.html с использованием formBuilder. Добавьте в нее необходимые контролы с подходящими валидаторами. Подключите созданную formGroup к элементам на шаблоне.
2. Добавьте типизированный `FormArray` для дополнительных участников и шаблон для добавления полей для новых участников в заявку. Пользователь должен уметь добавлять и удалять поля для их имён. Каждое добавленное имя обязательно и должно содержать минимум два символа. Каждый добавленный человек занимает одно место на экскурсию (контактное лицо тоже занимает одно место).
3. Добавьте валидатор на уровне формы. Он должен сверять количество мест с остатком для выбранной экскурсии. Переключение экскурсии, добавление или удаление участника должны сразу обновлять результат проверки. Покажите рядом с выбором экскурсии, сколько мест нужно группе и сколько доступно.
4. Добавьте асинхронный валидатор для почты через `isEmailAvailable()`. Запускайте проверку после ухода с поля. Покажите, что проверка идёт, и выведите ошибку, если на этот адрес уже есть бронь. Показывайте ошибки отдельных полей после ухода с поля.
5. Передавайте дополнительные имена в `book()`. Заблокируйте отправку, пока форма невалидна, идёт проверка почты или сохраняется бронь. При ошибке сохранения оставляйте введённые данные. При успехе очистите форму, включая добавленные поля, выведите информацию о бронировании ниже и обновите список свободных мест.

### Как проверить себя

- Добавьте участника и оставьте его имя пустым. После ухода с поля появится ошибка. После удаления поля эта ошибка перестанет блокировать отправку.
- Выберите обсерваторию, где доступно одно место, и добавьте участника. Форма должна показать нехватку мест. Выберите музей или удалите участника. Ошибка должна исчезнуть.
- Введите `reserved@example.com` и уйдите с поля. Сначала появится состояние проверки, затем сообщение о занятом адресе. Замените адрес на `visitor@example.com`. После успешной проверки форму можно отправить.
- Забронируйте два места в музее. Подтверждение должно показать два места, список экскурсий — одно оставшееся место в музее, а поля участников должны исчезнуть.
