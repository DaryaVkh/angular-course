# Интерактивная практика RxJS

Демонстрационное приложение к [лекции по RxJS](../lecture/RxJS%20%E2%80%94%20%D0%9B%D0%B5%D0%BA%D1%86%D0%B8%D1%8F%20%28Markdown%29.md).

В приложении 6 сценариев. Каждый показывает одну задачу в двух вариантах —
обычном и с операторами RxJS — на примере «настоящего» виджета: поиск в книжном
маркетплейсе, карточка товара, оформление заказа, торговый дашборд, профиль
пользователя, музыкальный плеер.

Визуализация событий — мраморная лента: события сценария появляются как шарики
на двух дорожках («Без RxJS» / «С RxJS»). Есть легенда обозначений, а клик по
шарику показывает детальное описание события. При переключении сценария лента
сбрасывается.

UI построен на [Taiga UI](https://taiga-ui.dev) в тёмной теме; палитра взята
из слайдов презентации. Для каждого сценария доступны ссылки на слайды лекции
и фрагменты кода обоих подходов (кнопка «Показать код» в шапке дорожки).

## Запуск

```bash
cd lessons/rxjs/demo
npm install
npm start
```

Приложение откроется по адресу `http://localhost:4200`.

## Сценарии и слайды лекции

| Сценарий | Виджет | Операторы | Слайды |
|---|---|---|---|
| Live search | Поиск в книжном маркетплейсе | `debounceTime`, `distinctUntilChanged`, `switchMap` | 31, 32, 37, 60 |
| Быстрая навигация | Карточка товара в каталоге | `switchMap` | 37, 53, 61 |
| Submit формы | Оформление заказа (корзина) | `exhaustMap` | 40, 62 |
| Параллельные запросы | Торговый дашборд (4 актива) | `mergeMap`, `forkJoin` | 38, 46, 63 |

Ссылки на слайды кликабельны — открывают соответствующую страницу PDF
презентации.

## Как работать

1. Выбери сценарий в боковой панели.
2. Повтори действие в обеих колонках (например, введи запрос в оба поиска).
3. Следи за мраморной лентой: порядок значений, ошибки, отмены, teardown.
4. Кликни по шарику, чтобы прочитать, что произошло.
5. Раскрой код обеих реализаций кнопкой «Показать код».
6. Сверь наблюдение со слайдами лекции.
